# Paycheck_Calc
A basic pre-tax calculator

# What this does
This is a simple calculator that prompts the user to input hours worked over the last two weeks
and the amount paid. It does accept floats and it does consider time and a half. After calculations, it gives you a rough estimate of what you earned *before tax.*
